회의 입장

    상대가 말할 수 있는 언어 → 내 언어 번역팩을 미리 받아두면 회의 중 지연이 없습니다.

    글로벌전략부 글로벌디지털팀 · 내부 시범 운영용 · 음성 인식은 Chrome 내장 기능(외부 서버 처리)을 사용하므로 대외비 회의에는 사용 전 정보보호 부서 확인이 필요합니다.

    우리은행
    연결 중…

    발언이 시작되면 내 언어로 번역된 기록이 쌓입니다.

    실시간 통역은 무료로 처리되고, AI는 여기서만 한 번 사용합니다.

    방법 A · 추가 비용 없음

    회의록 요청문과 전체 기록을 복사한 뒤 Claude 채팅에 붙여넣으면 됩니다. 쓰고 계신 구독 안에서 처리됩니다.

    방법 B · 버튼 한 번 (API 키, 회의록 1회분만 과금)

    아직 작성된 회의록이 없습니다.

    내 언어팩 상태

      음성 출력

      상대가 나와 다른 언어로 말할 때만 번역 음성이 나옵니다. 같은 언어끼리는 원음만 들립니다.

      회의 용어집

      자막이 반복해서 잘못 번역하는 단어를 바로잡습니다. 한 줄에 하나씩 "잘못된 표현=바른 표현".
